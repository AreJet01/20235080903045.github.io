理解JavaScript闭包

发布于2030年6月15日 by 白志杰

什么是闭包？

闭包是指有权访问另一个函数作用域中的变量的函数。创建闭包的常见方式是在一个函数内部创建另一个函数。

实际应用场景

function createCounter(){
  let count = 0;
  return function(){
    count++;
    return count;
  }
}
