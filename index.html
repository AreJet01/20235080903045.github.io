深入理解JavaScript闭包：原理与实战

📅 2030-06-15 👨‍💻 白志杰 JavaScript 前端进阶

🔍 什么是闭包？

闭包是指有权访问另一个函数作用域中变量的函数。它能让内部函数在外部函数执行完毕后，依然保留对外部作用域的引用。

闭包是前端面试高频考点，也是模块化、缓存、防抖节流的核心基础。

⚡ 经典应用：计数器

function createCounter(){
  let count = 0;
  return function(){
    count++;
    return count;
  }
}
const counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2

✅ 闭包常见用途

1. 实现私有变量与方法封装

2. 缓存计算结果，提升性能

3. 防抖、节流函数实现

4. 模块化开发，避免全局污染

CSS Grid 布局从入门到精通

📅 2030-06-15 👨‍💻 白志杰 CSS 布局

Grid 是目前最强大的二维布局系统，可以同时控制行和列，轻松实现复杂网页排版。

本博客整体布局正是使用 Grid 完成，自适应、响应式、结构清晰。

📌 Grid 核心优势

• 二维布局：同时控制行列

• 自适应强：自动填充、自动伸缩

• 代码简洁：大幅减少冗余 div 与 CSS

• 兼容性好：现代浏览器全覆盖
